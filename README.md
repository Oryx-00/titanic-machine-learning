# 🚢 Titanic Machine Learning - My 2nd Project

## Context
This repository contains my second Machine Learning project. After learning from Aurélien Géron's work, I decided to tackle the analysis and modeling of the famous Titanic dataset **entirely on my own**.

## Results
After a comprehensive data exploration and cleaning phase, I built a preprocessing pipeline and tested several models (KNN, Random Forest, SVM). I achieved great final results with an optimized Support Vector Machine (SVM), reaching an accuracy of about 83%.

## Key Takeaways
The biggest lesson I learned from completing this project independently is that **data processing is the most crucial step**. 

Once the features are properly selected, cleaned, encoded, and standardized, the different Machine Learning algorithms perform roughly the same on this type of dataset. Choosing and fine-tuning the algorithm helps squeeze out a few extra percentages, but it is truly the quality of the *preprocessing* that makes the model successful.
